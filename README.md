# comm-project

## Final Project Deliverable

This repository includes the ready-made Interpersonal Communication final project presentation:

- `How_to_Communicate_With_Me.pptx`

## How to Download

1. Open this repository on GitHub.
2. Click `How_to_Communicate_With_Me.pptx`.
3. Click **Download raw file** (or **View raw**) to save it.

## How to View/Edit

- **Microsoft PowerPoint**: open the `.pptx` directly.
- **Google Slides**: upload the `.pptx` to Google Drive, then open with Google Slides.
- **LibreOffice Impress**: open for free local viewing/editing.

## Notes

- The deck uses editable placeholders in brackets like `[Edit ...]` so personal details can be customized quickly.
- Symbolic visuals are built using slide shapes/icons (no external copyrighted images embedded).
